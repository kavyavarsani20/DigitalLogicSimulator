# Object-Oriented Digital Logic Circuit Simulator & Timing Analyzer

An extensible, modular hardware simulation engine implemented in C++ (C++17) for the **Object Oriented Programming (204ES)** course.

## Overview

Physical circuit prototyping on breadboards or FPGA boards is prone to wiring faults, short circuits, and damaged components. This project models digital electronic components as autonomous, polymorphic software objects capable of:
- Dynamic netlist interconnection.
- Two-phase signal propagation.
- Nanosecond-level gate propagation delay tracking.
- Edge-triggered sequential state capture (D Flip-Flop).

## Key Features

- **Object-Oriented Abstraction**: Base abstract class `Component` encapsulating input/output pin vectors, propagation latency, and state query interfaces.
- **Inheritance & Hierarchy**: Combinational gates (`AndGate`, `OrGate`, `XorGate`, `NandGate`, `NotGate`) and sequential elements (`Clock`, `DFlipFlop`) derived from `Component`.
- **Runtime Polymorphism**: Virtual method dispatch through pure virtual function `evaluate()`, allowing a uniform simulation engine loop to process heterogeneous components.
- **Defensive Error Handling**: Custom exception hierarchy (`CircuitException`, `InvalidConnectionException`) intercepting illegal wiring configurations and out-of-bounds pin indexes.
- **Operator Overloading**: Overloaded stream insertion `operator<<` for formatted console debugging and component inspection.
- **Smart Pointer Memory Management**: `std::shared_ptr` used across netlist connections to support multi-fanout topologies without memory leaks or double-free errors.
- **Interactive Console Interface**: Allows users to manually test individual gates, verify a 1-Bit Full Adder, or observe step-by-step edge-triggered clock cycles.
